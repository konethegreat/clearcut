# analytics (planned, Phase 4)

A Python sidecar for work where Python's ecosystem genuinely wins: payment-delay prediction,
cash-flow forecasting and OCR/LLM extraction of supplier documents. It will talk to the Rust
server over HTTP/gRPC and own no invoice business rules (those live in `clearcut-core`).

Nothing is implemented yet on purpose. See [ADR-0001](../../docs/adr/0001-multi-language-stack.md).
