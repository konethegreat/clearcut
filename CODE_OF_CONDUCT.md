# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful, assume good faith, give constructive feedback, and make participation harassment-free for everyone.

Report concerns privately to the maintainer via GitHub (@konethegreat). Maintainers may remove content or
contributors that violate these expectations.
