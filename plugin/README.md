# ClearCut plugin

Packages the `clearcut-mcp` server so Claude (and any MCP client) can calculate invoices,
check South African tax-invoice requirements and validate lifecycle transitions.

Status: **alpha**. The MCP entry runs from source via `cargo`; prebuilt binaries arrive in Phase 1.
See [docs/PHASES.md](../docs/PHASES.md).
