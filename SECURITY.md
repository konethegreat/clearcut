# Security Policy

ClearCut handles financial data. Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/konethegreat/clearcut/security/advisories/new).
Do not open public issues for security problems.

You can expect an acknowledgement within 5 working days. The project is pre-release (0.x):
only `main` is supported.
